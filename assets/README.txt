Drop real screenshots of your live portfolio sites here, named to match
js/config.js — e.g. restaurant.webp, field-fold.webp, gym-coach.webp, etc.
(see the "image" field on each project in ANTRA_CONFIG.portfolio).

Until a file exists at a given path, that project card automatically shows
a clean, category-styled preview instead — nothing will look broken or
show a missing-image icon either way.

Suggested screenshot size: 1200×800px (or similar 16:11-ish ratio), saved
as .webp for a good size/quality balance. A quick way to generate these:
open each live site, use your browser's full-page screenshot tool (or an
extension like GoFullPage), then compress/convert to .webp before adding
it here.
